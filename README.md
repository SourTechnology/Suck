# Suck — Math Helper

Suck is a small browser-based math helper. Enter an arithmetic expression to calculate it, or choose an example to try.

## Run locally

1. Save the app code as `index.html`.
2. Open `index.html` in a web browser.

No installation or build step is required.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Parentheses and decimals
- Powers using `^`
- Percentages, including expressions like `15% of 80`
- Square roots using `sqrt(number)`
- Example problems for quick testing

## Technologies

- HTML
- CSS
- JavaScript

The app is contained in one HTML file. Browsers don’t run TypeScript directly, so this version uses JavaScript.

## Note

Suck is a simple calculator, not a substitute for checking important calculations.
